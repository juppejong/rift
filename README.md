# Rift Companion

Nederlandstalige hulp bij League of Legends: champion-advies, tierlists per lane, runes, items, combo's, team builder en counter picker. Gamegegevens komen live van Riot Data Dragon; win rates uit een eigen steekproef via de Riot API.

**Live:** https://juppejong.github.io/rift/

## Bijwerken

Dubbelklik op `update.bat` (of start `update.bat data` / `update.bat reset` vanuit een terminal). Dat haalt nieuwe gegevens op, bouwt de site opnieuw op en pusht naar GitHub. Daarvoor is een geldige Riot-key nodig in `.env` van de app-map.
